Rehoboth Mezmur

An owner-operated tool that creates Amharic Protestant mezmur lyric videos from audio selected from Telegram, then optionally uploads them to the owner's YouTube channel.

The workflow verifies and times lyrics, produces the finished video and thumbnail, and prepares upload metadata. When YouTube uploading is enabled, new videos start private and enter a saved, randomized publication queue. Slots are four hours apart: the first is four hours ahead when the queue is empty, and new batches follow existing future slots. YouTube's built-in scheduler handles publication.

Google account access

This application uses YouTube API Services. Authorization is granted directly through Google. It checks the intended channel, uploads the owner's generated videos and thumbnails, and manages the publication schedule. It does not upload separate subtitle tracks.

This website does not collect Google passwords, accept credentials, or provide a public sign-in service. Publishing is operated through GitHub Actions with credentials supplied by the channel owner.

Privacy and control

Read the privacy policy and terms of use before authorization. This is a public repository: generated artifacts and saved upload identifiers can be publicly accessible even when the YouTube video is private.

You can stop workflow runs, change a video's visibility in YouTube Studio, and revoke Google's authorization.

Project and support

The app is maintained by the owner of the Protestant-Mezmur repository. Contact the operator using the support email shown on the Google consent screen. For non-sensitive technical questions, use the project issue tracker. Never post credentials or private account data in an issue.
